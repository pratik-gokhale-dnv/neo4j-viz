# neo4j-viz

Minimal starter implementation for exploring a Neo4j graph database with FastAPI + D3.js.

## Setup

Set Neo4j connection variables:

- `NEO4J_URI`
- `NEO4J_USERNAME`
- `NEO4J_PASSWORD`
- `NEO4J_DATABASE` (optional)

Install and run:

```bash
pip install -e .
python main.py
```

Open `http://localhost:8000`.
